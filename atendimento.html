O PROBLEMA

Três canais, vários celulares e uma equipe que não sabe quem respondeu o quê. O cliente repete a história, e quem tem pressa vai para o concorrente.

Como a equipe trabalha

  • ✓
    Fila organizada, com abas (Automático, Fila, Minhas, Todas, Fechadas e Arquivadas) e ações em várias conversas de uma vez.
  • ✓
    Cada número distribui do seu jeito: cada um pega, rodízio ou quem tem menos conversa.
  • ✓
    O vendedor dono do cliente é avisado quando o cliente escreve para outra pessoa.
  • ✓
    Passe a conversa para outra pessoa ou outro número, com o histórico junto.
  • ✓
    Nota interna com @menção: avisa só quem você marcou.
  • ✓
    Lista de quem esfriou e de pendências sem próximo passo, para agir antes de perder a venda.
  • ✓
    No celular, instala como aplicativo e avisa de mensagem nova mesmo com a tela fechada.
O FREIO

Cada pessoa vê só o que o seu papel permite.

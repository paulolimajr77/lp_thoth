# Thoth CRM — Landing Page

Landing page oficial de apresentação e vendas do **Thoth CRM** (Sistema Operacional de Vendas com Inteligência Artificial).

## Estrutura do Site

- `index.html`: Página principal de vendas e apresentação.
- `manual.html`: Guia prático da operação integrado.
- `css/`: Folhas de estilo (Design System oficial, responsividade, componentes e tipografia).
- `js/`: Scripts de interação, animações com GSAP / ScrollTrigger, controle de temas e formulários.
- `assets/`: Identidade visual, logotipos, ícones e ilustrações otimizadas.
- `img/`: Demonstrações e telas da plataforma em formato WebP.

## Tecnologias Utilizadas

- HTML5 semântico
- CSS3 moderno (Custom Properties, Glassmorphism, CSS Grid & Flexbox)
- JavaScript Vanilla + GSAP (GreenSock) & ScrollTrigger

Conhecendo a tela do Trunk SIP

Achar a tela e saber para que serve cada campo do cadastro do provedor de telefone.

01
Passo 1 de 4

Onde fica a tela

Abra "Configurações", no rodapé do menu lateral. Na parte "Dados e acesso" está o cartão "Trunk SIP". Clique nele.

  1. Trunk SIP

Dica: Só o administrador vê este cartão. A telefonia é um recurso opcional do servidor: esta tela só tem uso se a equipe do THOTH ligou a parte de telefone.

02
Passo 2 de 4

Para que serve

Para a IA fazer ligações de voz, a empresa contrata uma linha com um provedor de telefone pela internet (o "provedor SIP"). Aqui você guarda os dados de acesso dessa linha. Salvar aqui não liga nada sozinho: depois, a equipe do THOTH precisa colar um bloco de configuração no servidor de telefone, como diz o texto do topo.

  1. A ligação com o servidor é feita à mão
  2. Dados do provedor
03
Passo 3 de 4

Os dados da linha

Os quatro primeiros campos vêm do provedor, quando você contrata a linha. "Host" é o endereço do provedor (o texto cinza no campo é só um exemplo). "Porta" já vem com 5060, o número mais comum; só mude se o provedor pedir. "Usuário" e "Senha" são o login da sua linha.

  1. Endereço do provedor
  2. Porta (normalmente 5060)
  3. Login da linha
  4. Senha da linha

Dica: A senha fica guardada trancada: depois de salva, a tela mostra só os quatro últimos caracteres.

04
Passo 4 de 4

Campo opcional, chave e Salvar

"From-domain (opcional)" só é preenchido se o provedor exigir: normalmente é o endereço público do seu servidor. A chave "Ativo" diz se as ligações que o sistema faz saem por esta linha. Desligada, os dados ficam guardados e o sistema para de ligar por ela; as ligações recebidas não mudam, porque dependem do que foi colado no servidor. O botão "Salvar" grava tudo.

  1. Só se o provedor pedir
  2. Ativo
  3. Salvar

Dica: Na primeira vez a senha é obrigatória: sem ela, o sistema avisa e não salva. Depois, para salvar qualquer mudança (até desligar "Ativo"), digite a senha de novo.

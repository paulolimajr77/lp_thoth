Ligando a sua conta de anúncios

Saber onde e como colar o token de acesso da conta de anúncios, e o que cada campo da página de conexão pede.

01
Passo 1 de 5

Pelo caminho das Configurações

A página de conexão também abre por "Configurações", no rodapé do menu, além do botão da tela de Meta Ads. Ela fica na seção "Sua empresa", no cartão "Meta Ads". Clique nesse cartão, na coluna da direita (não no item "Meta Ads" do menu). Não confunda com o cartão "Conversões", que serve para outra coisa e pede um token diferente.

  1. Ligar a conta de anúncios
02
Passo 2 de 5

Uma ligação só para ler

A frase do alto garante que a ligação é só de leitura. Nada é criado, pausado ou alterado na sua conta de anúncios. O quadro azul diz o que você precisa trazer: um token de acesso, uma senha especial que o Facebook gera para o sistema poder ler os seus anúncios. Você gera o token no site Meta for Developers, com a permissão "ads_read".

  1. Nada muda na sua conta
  2. O que você precisa trazer

Dica: O token fica guardado de forma protegida e nunca é mostrado de volta, nem para você. Atenção: para gerar o token é preciso ter um aplicativo criado no Meta for Developers. Alguns tokens vencem em poucas horas. Se a tela de Meta Ads pedir um token novo pouco depois de ligar, foi isso. Gere um token de longa duração.

03
Passo 3 de 5

O campo do token

Cole o token no campo "Token de acesso". O "EAA..." cinza dentro do campo é só um exemplo de como o token começa. O campo ainda está vazio. Enquanto ele estiver vazio, ou com um token curto demais para ser inteiro, o botão "Salvar" fica apagado e, ao lado, aparece "Cole o token para poder salvar.". Na primeira vez, o token é obrigatório.

  1. Cole o token aqui
  2. Apagado até colar o token
  3. Por que não dá para salvar
04
Passo 4 de 5

A conta que abre primeiro

O campo "Conta padrão (opcional)" escolhe qual conta de anúncios a tela de Meta Ads abre primeiro. Escreva "act_" seguido dos números da conta, como no exemplo cinza dentro do campo. Se deixar em branco, a tela abre a primeira conta ativa que o token alcançar.

  1. Opcional: act_ e os números

Dica: Se o número não estiver nesse formato, ao salvar aparece "Confira os campos: algum valor não está no formato esperado.".

05
Passo 5 de 5

Pronto para salvar

Com o token colado, ele aparece como pontinhos, para ninguém ler por cima do seu ombro, e o botão "Salvar" acende. Ao salvar, aparece "Conexão salva." O campo do token fica vazio de novo, porque o token nunca é mostrado de volta. O sistema não testa o token na hora de salvar. Se ele estiver vencido ou sem a permissão "ads_read", um aviso na tela de Meta Ads diz o que fazer.

  1. Token colado
  2. Agora dá para salvar

Dica: Depois de ligada, esta página mostra também o botão "Desconectar". Ele apaga o token guardado e a tela de Meta Ads volta a pedir uma conexão.
